 🌍 ChatWorld

Welcome to ChatWorld — a place to meet people and chat with others around the world!

 💬 Features
- Global chat and private messaging
- Group chats
- Voice calls
- User profiles and profile pictures
- Photo sharing
- Online status indicators
- Animated emojis
- User blocking and nicknames

 ⚙️ Technology
- Frontend: HTML, CSS and JavaScript
- Backend: Supabase
- Hosting: GitHub Pages
- Voice calls: WebRTC

 🔒 Data & Storage
ChatWorld uses Supabase to manage user accounts, profiles, messages and uploaded photos.

 🚀 Getting Started
Visit the published ChatWorld website, create an account and start chatting!

Thanks for checking out ChatWorld!
